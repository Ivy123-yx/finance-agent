启动本地服务器（启用 AI 辅助）

以 file:// 双击打开时，浏览器会拦截向 api.deepseek.com 的跨域请求，导致 AI 辅助不可用。解决办法：用本地静态服务器以 http://localhost 方式打开。

方式一：双击本目录下的 start-server.bat

python -m http.server 8080

方式二：命令行手动执行

cd 本文件所在目录
python -m http.server 8080
# 然后在浏览器打开 http://localhost:8080
启动后回到本页面，重新生成即可正常调用 DeepSeek 生成 AI 说明。若仍失败，多为网络或密钥问题（见顶部「AI 辅助」状态与提示）。
